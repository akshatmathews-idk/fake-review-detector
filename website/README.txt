INSTALL AND RE-EXPORT

1. Copy website/index.html, style.css, script.js, inference.js into your existing website/ folder.
2. Keep your trained models/final_linear_svc_pipeline.joblib in models/.
3. Replace src/export_website.py with export_website_updated.py (rename it export_website.py).
4. Replace src/export_browser_model.py with export_browser_model_updated.py (rename it export_browser_model.py).
5. Replace src/generate_browser_test_cases.py with generate_browser_test_cases_updated.py (rename it generate_browser_test_cases.py).
6. From the project ROOT, run:
   python src/export_website.py
   python src/export_browser_model.py
   python src/generate_browser_test_cases.py
7. Check:
   ls -lh website/data/results.json website/data/browser_model.json website/data/browser_test_cases.json
8. Start Live Server at website/index.html.

The updated results exporter reads the current CSVs and raw dataset. It derives category/rating OOF error rates from the misclassified-only OOF CSV joined with the original review metadata. The example generator picks real OR and CG labelled reviews that the saved final model classifies correctly. Examples are samples, not representative evidence of general performance.

Important: the site expects browser_model.json and browser_test_cases.json inside website/data/. They are generated by the two Python scripts; they are not included in this source-code package.
