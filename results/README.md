# Results and generated artifacts

- `metrics/model_comparison_cv*.csv` and `metrics/feature_experiment_results.csv` support Notebooks 03–05.
- `improvement_no_stopwords/` contains the controlled tuning summaries from Notebook 06. Its selected LinearSVC is the top CV candidate, not the deployed model.
- `final_logistic_regression/` contains the final Logistic Regression metadata and evaluation outputs.
- `linearsvc_vocab_experiment/` contains the compact LinearSVC vocabulary-size experiment (Notebook 09).
- `final_model_comparison/` contains the direct Logistic Regression vs LinearSVC (10k) comparison (Notebook 10).
- `figures/` and `predictions/` are regenerated by the notebooks or source scripts.

Use `final_logistic_regression/` for the selected model's final metrics. Do not use historical or experimental LinearSVC outputs as if they were final Logistic Regression results.
